# Security and License Rules

- Prefer CC0 for art assets intended to live in a public repository.
- MIT/MPL/GPL code may have notice/source obligations; keep tool code clearly separated from generated/exported game assets.
- Anything marked VERIFY_BEFORE_VENDORING must not be copied into the project until its exact license is confirmed.
- Do not redistribute purchased or account-gated source files unless their license explicitly allows it.
- Poly Haven assets are CC0, but the website/API have separate usage terms; pin downloaded asset files rather than scraping the site.
- Roblox Creator Store assets can contain scripts. Environment props should ship with no third-party scripts unless reviewed line-by-line and explicitly approved.
- Keep original file hashes and modification history for every adopted asset.
- Never treat a Studio instance or .blend file as canonical source data.
- Do not use scraped Google Street View / Google 3D city data.
