# UPLB Architecture Kit

The UPLB Architecture Kit is the reusable vocabulary used to model the majority
of developed campus without creating every building from scratch.

The authoritative module definitions are in:

`data/modeling/architecture-kit-v0.1.json`

`prototypes/` contains automatically generated **dimension prototypes only**.
They are not final UPLB art assets and should not be uploaded as production
assets without visual/source review.

Production principle:

`canonical footprint + verified dimensions + architecture family + reusable modules -> building asset`

Hero landmarks may override the kit completely.
